# POS108 Demo (Windows)

ลองระบบขายหน้าร้าน POS108 ได้เลย ไม่ต้องติดตั้งอะไร ข้อมูลทั้งหมดเป็นของจำลอง ไม่ส่งออกอินเทอร์เน็ต
Try the POS108 point-of-sale on Windows — nothing to install, all data is simulated and stays on your computer.

## ดาวน์โหลด / Download

ไปที่หน้า **[Releases](../../releases/latest)** แล้วเลือกโหลดชุดที่ตรงกับร้านของคุณ:

| ชุด | ไฟล์ | เหมาะกับ |
|---|---|---|
| ร้านกาแฟ | `pos108-demo-cafe-win-x64.zip` | ขายตรงที่เคาน์เตอร์ |
| ร้านอาหาร | `pos108-demo-restaurant-win-x64.zip` | นั่งที่ร้าน (เลือกโต๊ะ) / ซื้อกลับ / โทรมาสั่ง + จอครัว |
| ผับ-บาร์ | `pos108-demo-bar-win-x64.zip` | นั่งที่โต๊ะ/ห้อง VIP อย่างเดียว + นั่งดริ้งค์ (Lady Drink) |

## วิธีใช้

1. แตกไฟล์ zip ทั้งโฟลเดอร์
2. ดับเบิลคลิก `Start-cafe.cmd` / `Start-restaurant.cmd` / `Start-bar.cmd` (แล้วแต่ชุดที่โหลด) — เปิดแบบเต็มจอ เข้าระบบอัตโนมัติ
3. ออก: เมนูซ้ายบน → "ปิดเครื่อง" หรือ Alt+F4

รายละเอียด บัญชีทดสอบ และหน้าเว็บผู้จัดการ/จอครัว อยู่ในไฟล์ `README-th.txt` ในแต่ละชุด

## ข้อควรรู้

- รองรับ Windows 64-bit เท่านั้น (Mac / Linux ยังไม่มี)
- Windows อาจเตือน SmartScreen ครั้งแรก เพราะไฟล์ยังไม่ได้เซ็นใบรับรอง: เลือก "ข้อมูลเพิ่มเติม" → "เรียกใช้งานต่อไป"
- QR พร้อมเพย์ใน demo ใช้เบอร์ปลอม สแกนด้วยแอปธนาคารไม่ผ่าน — ใช้ปุ่ม "ยืนยันรับเงิน" แทน
- เครื่องพิมพ์ใช้ไม่ได้ใน demo (ป้าย "พิมพ์ไม่ได้" เป็นเรื่องปกติ)
- เซิร์ฟเวอร์ในชุดนี้เป็นเซิร์ฟเวอร์จำลองสำหรับ demo ไม่ใช่ระบบหลังบ้านจริง

ตรวจสอบความถูกต้อง: ไฟล์ zip แต่ละชุดมี SHA-256 ระบุในหน้า Release
